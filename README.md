# 🐦 Tweet Sentiment Analyzer

A web-based NLP project that classifies the **sentiment of tweets** as **Positive** or **Negative**, along with a confidence score. It also supports topic-level sentiment aggregation for batch analysis.

## 🚀 Features

- Sentiment classification using **Logistic Regression** and **TF-IDF Vectorization**
- Built with **Flask** for backend
- Deployed on **Render**
- Supports keyword/topic-based sentiment aggregation
- Lightweight and optimized for **small-scale datasets**
- Secure handling of inputs and API endpoints

## 🧠 Tech Stack

- **Python**
- **Flask**
- **Scikit-Learn**
- **NLTK**
- **HTML/CSS (for frontend)**
- **Render** (Deployment platform)

## 📊 Model Details

- **Vectorization:** TfidfVectorizer (`sklearn`)
- **Classifier:** LogisticRegression
- **Trained On:** Manually labeled tweets
- **Metrics Used:** Accuracy, Precision, Recall, F1-score
